## 🚨 What is DPRES?

**DPRES** is a comprehensive, interactive disaster preparedness and emergency response education platform built for **schools and colleges across India**. It combines structured curriculum, interactive simulations, and real-time alert awareness to build disaster-resilient campuses.

> *"Knowledge is the first responder."*

---

## ✨ Features at a Glance

| Feature | Description |
|---|---|
| 🏫 **Structured Modules** | 48 training modules across 6 core curriculum areas |
| 🌊 **Disaster Response Guides** | Detailed protocols for Flood, Earthquake, Cyclone, Fire & Chemical hazards |
| 📚 **Certified Courses** | Programs for students, faculty, and CERT volunteers |
| 🛡️ **Emergency Protocols** | 5-step universal campus action protocol (SOP) |
| 📋 **Free Resources** | Downloadable checklists, maps, manuals & drill kits |
| 🧠 **Knowledge Quiz** | Interactive 5-question assessment with instant feedback |
| 📡 **Live Alert Ticker** | Real-time disaster awareness banner |
| 📱 **Fully Responsive** | Optimized for mobile and desktop |

## 🚀 Getting Started

No build tools required. DPRES is a **pure HTML/CSS/JS** single-page application.

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/dpres-edusystem.git
cd dpres-edusystem
```

### 2. Open in Browser

```bash
# Option A — just open directly
open index.html

# Option B — run a local server (recommended)
npx serve .
# or
python3 -m http.server 8080
```

### 3. Visit `http://localhost:8080` 🎉

## 🌏 Disaster Coverage

DPRES covers the most critical hazards relevant to India:

- 🌊 **Flood** — Most common disaster; 150+ events/year across 22 states
- 🌍 **Earthquake** — Zone V coverage; 60-second response window
- 🌀 **Cyclone** — Eastern coast risk; 5–6 major events/year
- 🔥 **Fire** — Structural fires; 2-minute spread window
- ☢️ **Chemical Hazard** — HAZMAT awareness near 3000+ industrial zones
